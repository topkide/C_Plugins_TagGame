# TagGame - 술래잡기 플러그인

Paper 1.21.4 단일 서버용 술래잡기 미니게임 플러그인.

## 빌드

JDK 21 필요.

```bash
./gradlew build
```

빌드 결과물: `build/libs/TagGame-1.0.0.jar` → 서버 `plugins/` 폴더에 넣고 재시작.

## 게임 흐름

1. 플레이어들이 `/술잡 참가` 로 참가 (대기 상태에서만)
2. 관리자가 `/술잡 시작` → 술래 랜덤 선정, 역할 타이틀 표시, 술래에게 "술래의 검"(나무 검) 지급
3. 준비시간(기본 60초) 동안 술래는 이동 불가 + 실명, 시민은 도망쳐 숨음 (보스바 카운트다운)
4. 준비시간 종료 → 전체에 「시작!!」 타이틀, 게임 타이머 시작 (기본 300초, 보스바 표시)
5. 술래가 검으로 시민을 1회 타격 → 잡힘 (데미지/넉백 없음, 태그 판정 전용)
6. 모든 시민이 잡히면 → 「술래 승!!!」 / 타이머가 0이 되면 → 「시민 승!!!」
7. 게임 종료 후 상태 초기화, 대기 상태로 복귀

## 명령어

### 일반 (모든 플레이어)

| 명령어 | 설명 |
|---|---|
| `/술잡 참가` | 게임 참가 (대기 중에만, 중복 참가 불가) |
| `/술잡 나가기` | 참가 취소 (대기 중에만) |
| `/술잡 상태` | 현재 상태/술래/생존 시민/남은 시간 확인 |
| `/술잡 도움말` | 도움말 (권한에 따라 표시 항목 다름) |

### 관리자 (OP / `suljab.admin`)

| 명령어 | 설명 |
|---|---|
| `/술잡 시작` | 게임 시작 (최소인원·술래수·시민처리 설정 검증) |
| `/술잡 중단` | 일시정지 (타이머·판정 정지, 참가자 이동 제한, 상태 유지) |
| `/술잡 재개` | 중단된 시점부터 이어서 진행 (준비시간 중 중단도 이어서) |
| `/술잡 종료` | 게임 완전 종료 및 전체 초기화 |
| `/술잡 강제종료` | 즉시 강제 종료 (오류 시 사용) |
| `/술잡 설정 타이머 <초>` | 게임 제한시간 (기본 300) |
| `/술잡 설정 준비시간 <초>` | 술래 이동 불가 시간 (기본 60) |
| `/술잡 설정 최소인원 <숫자>` | 시작 최소 인원 (기본 2) |
| `/술잡 설정 술래수 <숫자>` | 랜덤 선정 술래 수 (기본 1) |

### 게임 정책 (`/술잡관리`, 관리자 전용)

| 명령어 | 설명 |
|---|---|
| `/술잡관리` | 현재 정책 설정 상태 확인 |
| `/술잡관리 시민처리 <관전\|제외>` | 잡힌 시민 처리 방식. **미설정 시 게임 시작 불가** |
| `/술잡관리 공지 <켜기\|끄기>` | 시민 잡힘 전체 공지 on/off |
| `/술잡관리 술래퇴장 <종료\|재선정>` | 술래 전원 퇴장 시: 게임 종료 / 시민 중 새 술래 선정 |

명령어 별칭: `/술래잡기`, `/tag`, `/tagadmin`

## 동작 규칙 상세

- **술래의 검**: PDC 태그로 식별되는 게임 전용 나무 검. 데미지·넉백 완전 캔슬(비참가자 포함 무반응), 버리기/상자 이동 불가, 분실 시 매초 자동 재지급, 게임 종료 시 자동 회수. 기존 인벤토리 아이템은 건드리지 않으며 가득 찬 경우 비우라는 안내만 표시.
- **잡힌 시민 (관전 모드)**: 스펙테이터 전환. 게임 종료 시 잡힌 위치·원래 게임모드로 복구 (오프라인이면 다음 접속 시 복구).
- **잡힌 시민 (제외 모드)**: 게임에서만 제외, 서버에서는 일반 플레이어로 유지.
- **사망/퇴장/재접속**: 게임 중 시민이 죽거나 서버를 나가면 잡힌 것으로 처리. 재접속해도 복귀 불가(잡힌 상태 유지).
- **술래 퇴장**: 관리자에게 알림. 술래가 전원 퇴장하면 정책에 따라 종료 또는 재선정.
- **이동 제한**: PlayerMoveEvent 기반(블록 좌표 변경 시 원위치, 시선 회전 허용). 엔더진주/후렴과 우회 차단.
- **일시정지**: 보스바·타이머·판정 정지, 참가자 전원 이동 제한, 시간·역할·위치 그대로 유지. 재개 시 정확히 그 시점부터 카운트다운.
- 모든 설정은 `config.yml` 에 즉시 저장되어 서버 재시작 후에도 유지.

## config.yml

시간·인원·술래수, 잡힌 시민 처리, 공지 여부, 보스바 제목/색상, 술래의 검 이름, 모든 메시지 문구(& 색코드)를 수정할 수 있습니다. 명령어로 변경한 값도 이 파일에 저장됩니다.

## 참고 사항

- 게임 상태는 메모리 기반이므로 서버 재시작/리로드 시 진행 중이던 게임은 초기화됩니다.
- 보스바는 서버 전체 플레이어에게 표시됩니다.
